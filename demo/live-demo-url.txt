FULL STREAMLIT APP (run locally)
The complete 7-tab Streamlit app with Advisor Chat, Metrics Panel, and BOB Quality
Panel requires Python and runs locally:

  pip install streamlit pandas
  python -m streamlit run src/app.py --server.port 8502

App opens at: http://localhost:8502

See docs/setup-guide.md for full instructions.
